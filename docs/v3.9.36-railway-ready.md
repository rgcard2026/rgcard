# RG-Card v3.9.36 — Railway-ready

هذه النسخة جاهزة للنشر على Railway مع **Volume واحد** يحفظ:

- قاعدة SQLite: `/data/rg-card.db`
- كل اللوجوهات والصور المرفوعة: `/data/uploads`
- النسخ الاحتياطية اليدوية: `/data/backups`

## قبل أول Deploy

1. اجعل Repository على GitHub **Private**.
2. لا ترفع ملف `.env` أو قاعدة `prisma/dev.db` إلى GitHub.
3. من Railway أنشئ Project ثم اختر **Deploy from GitHub Repo**.
4. أضف Volume إلى نفس Service واجعل Mount Path:

```text
/data
```

5. من Variables أضف القيم التالية، واستخدم قيمة عشوائية مستقلة لكل سر. لا تستخدم
   القيم الافتراضية الموجودة في `.env.example`:

```env
DATABASE_URL=file:/data/rg-card.db
RG_CARD_DATA_DIR=/data
RG_CARD_DB_PATH=/data/rg-card.db
RG_CARD_UPLOADS_PATH=/data/uploads
AUTH_SECRET=<long-random-value>
SESSION_SECRET=<long-random-value>
DATA_ENCRYPTION_SECRET=<long-random-32-plus-char-value>
NEXT_PUBLIC_WHATSAPP_NUMBER=201000033494
NEXT_PUBLIC_ENABLE_LOGIN_ENCRYPTION=true
LOGIN_MAX_FAILED_ATTEMPTS=3
LOGIN_TEMP_BLOCK_MINUTES=15
SESSION_MINUTES=30
SECURITY_ALERT_TIMEOUT_MS=6000
TZ=Africa/Cairo
```

6. بعد نجاح الـ Deploy، من **Settings → Networking** اضغط **Generate Domain**.
7. انسخ الدومين العام الكامل مع `https://` وأضفه في Variables:

```env
RG_CARD_PUBLIC_URL=https://your-generated-domain.up.railway.app
```

هذا الدومين يُستخدم في QR codes وملفات PDF؛ لا تستخدم عنوان Railway الداخلي.
حافظ على `DATA_ENCRYPTION_SECRET` نفسه بعد تخزين بيانات مشفرة، وإلا لن يمكن فك
تشفير البيانات السابقة. غيّر كلمة مرور المدير الافتراضية فورًا إذا شغّلت بيانات
البذرة التجريبية.

## نقل قاعدة البيانات واللوجوهات الحالية

بعد إنشاء الـ Volume وربطه بالخدمة، ثبّت Railway CLI محليًا ثم سجّل الدخول واربط المشروع. من فولدر المشروع المحلي:

```bash
railway login
railway link
railway volume list
```

ثم ارفع الداتا إلى Volume مع استبدال `YOUR_VOLUME_NAME` باسم الـ Volume الظاهر لديك:

```bash
railway volume files --volume YOUR_VOLUME_NAME upload prisma/dev.db /rg-card.db --overwrite
railway volume files --volume YOUR_VOLUME_NAME upload public/uploads /uploads --overwrite
```

بعد الرفع، أعد تشغيل الخدمة من Railway Dashboard. التطبيق سيستخدم الداتا الحالية تلقائيًا.

> مهم: لا تنفّذ `npm run db:seed` بعد نقل قاعدة البيانات الحالية، لأنه مخصص لأول تشغيل فقط.

## النسخ الاحتياطي

فعّل Volume Backups من Railway Dashboard. يمكنك كذلك أخذ نسخة يدوية داخل الخدمة أو باستخدام Railway CLI. لا تحذف الـ Volume لأن حذفها يحذف بيانات SQLite والصور بعد فترة الاستعادة المتاحة في Railway.
