# RG-Card v3.9.26 — Logo Rendering Hotfix

## What was fixed
- Corrected the CSS scoping issue that prevented logo constraints from applying inside the reusable `PlaceLogo` component.
- Logos now render inside fixed, centered frames with strict max dimensions in both the catalogue and New Arrival / Coming Soon banner.
- The banner avoids visible duplicate logo sets when the admin has selected one to three places: those cards remain centered and have a subtle motion effect.
- Four or more selected places use the continuous horizontal marquee.
- Existing admin banner controls remain unchanged: `isActive`, `isFeatured`, and `sortOrder`.
