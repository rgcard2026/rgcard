# RG-Card v3.9.24 — Banner and place-card refinement

## User portal

- Replaced the previous New Arrival strip with a fixed-height, animated logo-only banner.
- Banner cards only display the place logo. Place names, discount values, descriptions, and other details are intentionally excluded.
- Every logo card links to the existing place-details route.
- The motion pauses on hover/focus and is disabled for users who prefer reduced motion.
- Place cards now show only the logo and place name. The complete card is clickable and opens the existing details page.
- Desktop and mobile CSS is included; logo images use `object-fit: contain` so they are not cropped.

## Admin control

The existing per-place controls are retained and are the source of truth for the banner:

- `إظهار في بانر New Arrival / Coming Soon` controls whether the place appears in the banner.
- `ترتيب الظهور في البانر` controls the sequence; lower values appear first.
- `مفعل` controls whether the place is visible to users at all. An inactive place cannot appear in the banner.

No Prisma schema change is required, so existing records and all earlier dashboard functionality remain intact.
