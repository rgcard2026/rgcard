# RG-Card v3.9.61 — إصلاح استجابة أزرار إدارة المستخدمين

## التعديلات

- إضافة مؤشر تحميل واضح لكل عملية داخل لوحة المستخدمين لمنع الضغط المتكرر.
- عرض نتيجة الحفظ والتشغيل والحذف والاستيراد والخصومات في Snackbar فوق الـDrawer بدل إخفائها خلف اللوحة الجانبية.
- تحديث بيانات المستخدم داخل اللوحة فور نجاح الحفظ أو تشغيل الحساب.
- معالجة أخطاء الشبكة وإظهار رسالة واضحة بدل بقاء الواجهة دون رد.
- منع تكرار الطلبات أثناء وجود عملية جارية.
- تحسين إدارة التركيز عند فتح وإغلاق Drawer وDialog لتجنب تحذير `aria-hidden`.
- تعطيل Restore Focus للمودالات المستخدمة في هذه الصفحة لتفادي بقاء التركيز داخل عنصر مخفي.

## ملاحظة المتصفح

أخطاء React hydration التي يظهر معها `inpage.js` غالبًا سببها إضافة متصفح تعدّل الصفحة قبل تحميل React. اختبر أيضًا في نافذة Incognito بدون الإضافات للتأكد.
