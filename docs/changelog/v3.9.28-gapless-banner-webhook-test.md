# RG-Card v3.9.28

## Banner

- New Arrival / Coming Soon uses a seamless duplicate-group marquee.
- The carousel keeps moving with no blank interval, including when only one or two places are selected.
- The public banner shows logos only; selecting a logo opens its place details page.

## Add a place to the banner

1. Open **Admin → New Arrival / Coming Soon**.
2. Search by place name or category.
3. Press **إضافة**.
4. Use the up/down arrows in the selected list to choose the public order.
5. Use the red delete icon to remove it from the banner only.

A place must be enabled in **الأماكن والعروض**. Uploading a logo there is recommended so the banner is visually consistent.

## Webhook testing

Set `SECURITY_ALERT_WEBHOOK_URL` to a test endpoint such as Webhook.site, restart the app, enable security alerts, and use the test button. Webhook.site receives the JSON body for verification; it is not a WhatsApp delivery service by itself. Use an automation bridge such as n8n, Make, Twilio, or Meta WhatsApp Cloud API to turn the incoming webhook into a WhatsApp message.
