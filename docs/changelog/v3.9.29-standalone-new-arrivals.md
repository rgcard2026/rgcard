# RG-Card v3.9.29 — Standalone New Arrival and webhook dashboard setup

## New Arrival / Coming Soon

- Uses its own `NewArrival` database table and is no longer selected from Places or Offers.
- Each item stores only an internal admin label, a logo image, an external HTTPS destination URL, active state, and position.
- The user-facing marquee shows logos only. Clicking a logo opens the configured external page in a new browser tab.
- User-facing offers and places keep their existing behavior and detail pages.
- Run `npx prisma generate` then `npm run db:push` after updating, because a new table is added.

## Security webhook

- The Security Alerts page now accepts a webhook URL directly in the admin dashboard.
- URL and optional token are encrypted using `DATA_ENCRYPTION_SECRET` before saving to `AppSetting`.
- Environment variables remain supported and override dashboard configuration when present.
- `webhook.site` is suitable for verifying the POST payload. Connect the same payload to n8n/Make/Twilio/Meta for real WhatsApp delivery.
