# RG-Card v3.9.22 — Client revisions

- New Arrival / Coming Soon is now a logo-only horizontal banner.
- The public places catalogue is logo-only; opening a logo displays the complete place, branch, and offer details.
- Public search now considers place name, description, discount, banner text, category, branch names, addresses, phones, governorates, map links, and offer details.
- User-side layout is optimized for narrow mobile screens.
- Admin layout is fluid for mobile, tablet, and desktop; the sidebar remains a temporary drawer on mobile.
- Added an expandable editor button to normal admin text fields, providing a larger modal text box for viewing and editing long values.
- Admin logs use compact cards on mobile instead of a wide table.
