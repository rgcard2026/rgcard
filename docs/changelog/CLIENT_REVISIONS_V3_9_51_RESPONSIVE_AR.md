# RG-Card v3.9.51 — Client UI Re-enabled with Responsive Auto-Fit

هذه النسخة تعيد تعديلات واجهة العميل التي تم التراجع عنها في v3.9.50، مع طبقة Responsive جديدة لضمان ملاءمة أفضل للشاشات المختلفة.

## Included
- Arabic / English toggle with persisted preference.
- Light / Dark mode with persisted preference.
- Repeated outline watermark.
- Membership card scroll experience and desktop card flip.
- Logo entrance animation.
- Admin translated sidebar, active navigation style, logo/name directories, and edit drawers.
- Responsive auto-fit layer for common widths from 320px phones through tablets, laptops, and wide desktop displays.

## Responsive behavior
- Phones under 480px: compact navigation, one-column admin cards, full-width drawer controls and buttons.
- 480px–767px: optimized phone landscape and narrow-tablet spacing.
- 768px–1099px: tablet layout uses a temporary admin drawer to preserve content space.
- 1100px+: permanent admin sidebar and multi-column directory layouts.
- Member card flip remains on laptop/desktop; smaller touch devices keep the front of the card visible while scrolling.

No database schema, production data, credentials, uploads, or environment variables are changed.
