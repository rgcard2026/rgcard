# RG-Card v3.9.65 — تحسين استوديو التصميم ورسائل الإجراءات

هذه النسخة تراكمية فوق v3.9.64 وتعالج ملاحظات العميل التالية:

## 1) حفظ استوديو التصميم

- إضافة Toast واضح عند نجاح أو فشل الحفظ.
- الزر الأساسي أصبح «حفظ وإغلاق الصفحة» ويعيد الأدمن إلى لوحة التحكم بعد نجاح الحفظ.
- إضافة زر «حفظ بدون مغادرة» لمن يريد متابعة المعاينة.
- إضافة زر «إغلاق بدون حفظ».
- إضافة رسائل واضحة عند رفع صورة الخلفية أو استعادة القيم الافتراضية.

## 2) صفحة المستخدمين

- زر حالة الحساب أصبح Toggle فعليًا:
  - يظهر «إيقاف الحساب» عندما يكون الحساب نشطًا.
  - يظهر «تشغيل الحساب» عندما يكون الحساب موقوفًا.
- بعد نجاح التفعيل/الإيقاف يتم إغلاق اللوحة الجانبية وعرض رسالة واضحة.
- بعد نجاح حفظ المستخدم يتم إغلاق اللوحة وعرض رسالة نجاح.
- فصل تغيير كلمة المرور داخل اختيار مستقل.
- لا يتم إرسال حقل كلمة المرور إلا بعد تفعيل «تعيين كلمة مرور جديدة» وكتابة كلمة مرور قوية ومتطابقة.
- زيادة مدة ظهور رسائل النجاح والخطأ.
- تحديث القائمة بعد كل عملية ناجحة.

## 3) استوديو تصميم أكثر تخصيصًا

تمت إضافة إعدادات مستقلة لـ:

- خط النصوص العامة.
- خط العناوين.
- خط الأزرار والقوائم.
- أكثر من 20 اختيارًا للخطوط العربية والإنجليزية.
- وزن النصوص والعناوين والأزرار بشكل منفصل.
- Italic للنصوص والعناوين والأزرار بشكل منفصل.
- حجم النص العادي.
- حجم H1 وH2 وH3.
- حجم عنوان الكارت.
- حجم نص الأزرار.
- حجم نص الحقول.
- حجم نص القوائم والـSidebar.
- حجم النصوص الصغيرة والملاحظات.
- ارتفاع السطر.
- تباعد الحروف.
- استدارة الأزرار والكروت وحقول الإدخال.
- ألوان النص الثانوي، خلفية الحقول، النجاح، والخطأ.

كل القيم تحفظ داخل جدول AppSetting الحالي؛ لا توجد Migration أو تغييرات Prisma مطلوبة.
