# RG-Card v3.9.49 — استيراد ملف العميل الكامل

## ما الذي يفعله التحديث؟
- يضيف زرًا واحدًا داخل **الأدمن → الأماكن والعروض** باسم: `استبدال بيانات التجربة الآن`.
- يحذف بيانات التجربة الحالية الخاصة بالأماكن والعروض والفئات وعناصر **New Arrival**.
- يستورد الملف المعتمد المرفق من العميل:
  - **167 مكانًا**
  - **167 عرضًا**
  - **22 فئة**
  - **163 لوجو مربوطًا بالأماكن**
- لا يحذف المستخدمين أو حسابات الأدمن أو إعدادات النظام أو الكروت.
- كل مكان يتم ترتيبه مثل ملف Excel، وتظهر فروعه/مناطقه داخل صفحة التفاصيل.
- الـ New Arrival يبدأ فارغًا بعد الاستبدال حتى يختار الأدمن العناصر المناسبة من واجهة البانر.

## طريقة التنفيذ بعد الـ Deploy
1. سجل دخول كـ **Owner**.
2. افتح: `Admin → الأماكن والعروض`.
3. اضغط: **استبدال بيانات التجربة الآن**.
4. عند طلب التأكيد، اكتب: `استبدال`.
5. انتظر رسالة النجاح ثم افتح واجهة المستخدم وتحقق من العروض.

> هذه العملية مقصودة لمرة الاستبدال الأولى فقط. لا تضغط الزر مجددًا بعد أن تبدأ إضافة تعديلات جديدة من لوحة الأدمن.
