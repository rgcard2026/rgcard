# RG-Card v3.9.68 — توحيد أزرار التفعيل والإيقاف

هذا التحديث يطبق زر التفعيل/الإيقاف الأصلي الجديد الذي تم اعتماده في صفحة المستخدمين على جميع مفاتيح التشغيل الثنائية داخل لوحة الإدارة.

## ما تم تنفيذه

- إنشاء مكوّن موحد باسم `AdminActionToggle`.
- استخدام زر HTML أصلي من النوع `button` بدل `MUI Switch`.
- دعم واضح لحالات التشغيل والإيقاف، وتعطيل الزر أثناء العمليات الجارية.
- الحفاظ على دعم RTL وDark Mode والوصول عبر لوحة المفاتيح و`aria-pressed`.

## الصفحات المشمولة

- المستخدمون والكروت:
  - تغيير كلمة المرور عند أول دخول.
  - تعيين كلمة مرور جديدة.
  - تفعيل الحساب.
- المسؤولون والصلاحيات:
  - تفعيل حساب المسؤول.
  - التحويل إلى Owner.
- الأماكن والعروض:
  - إظهار أو إخفاء المكان للمستخدمين.
- وصل حديثًا / قريبًا:
  - إظهار أو إخفاء العنصر للمستخدمين.
- استوديو التصميم:
  - تفعيل أو إيقاف صورة الخلفية.
- التنبيهات الأمنية:
  - تفعيل أو إيقاف التنبيهات.

لم يتم تحويل مربعات الاختيار الخاصة بتحديد الصفوف أو اختيار الصلاحيات أو المحافظات؛ لأنها ليست مفاتيح تشغيل/إيقاف، بل عناصر اختيار متعددة.
