# RG-Card v3.9.31 — Public New Arrival Feed and Endless Loop

- The actual public offers page now requests `/api/new-arrivals` and renders only the independent `NewArrival` records added through the admin dashboard.
- Banner logos open their configured external HTTPS target in a new browser tab.
- The marquee uses two equal long groups and translates exactly 50%, giving an endless loop without a blank gap, reset, or hover pause.
- The public feed is explicitly sent with no-cache headers, so newly saved banners become visible after a normal refresh.
