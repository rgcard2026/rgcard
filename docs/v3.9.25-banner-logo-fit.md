# RG-Card v3.9.25 — Banner and logo fit refinement

## Updated user catalogue

- New Arrival / Coming Soon is now populated **only** from places selected by the administrator (`isFeatured`) and that are currently active (`isActive`). There is no fallback to unrelated places.
- Featured places are sorted by `sortOrder` ascending, then by place ID.
- The banner uses fixed-size logo cards, a controlled moving track, edge fade masks, pause-on-hover/focus, and reduced-motion support.
- Banner cards contain logos only; visible names and offer details were removed.
- Catalogue place cards show the complete logo within a restrained fixed frame plus the place name only.
- Mobile logo frames and banner cards are resized for narrow screens.

## Updated admin control

- Added a dedicated banner status card in Admin Places showing all active banner items in their live display order.
- Added an `إدارة عناصر البانر` filter button to quickly show only places configured for the banner.
- The existing controls remain the source of truth: `مفعل`, `إظهار في البانر`, and `ترتيب البانر`. Save each changed place after editing.
- CSV imports now accept optional `sortOrder` / `bannerOrder` / `ترتيب البانر` values for new places and updates.

## No database migration required

The implementation uses existing fields (`isActive`, `isFeatured`, `sortOrder`) and preserves the current database schema, pagination, card-design settings, WhatsApp message settings, and responsive admin sidebar.
