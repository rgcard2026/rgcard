# RG-Card v3.9.50 — Client UI Revision

## User portal
- Repeated foreground watermark is now hollow / outline only.
- Global Arabic / English switch and light / dark mode switch.
- Membership landing and card view are combined into a scroll experience with a card flip.
- Public place logos animate into view.

## Admin portal
- Global Arabic / English switch and light / dark mode switch.
- Arabic sidebar wording, active navigation highlighting, and translated primary navigation.
- Places, New Arrival / Coming Soon, users, and admins now use compact logo/name directories.
- Details and edits open in side drawers instead of inline, dense forms.
- Pagination is shown only below each compact directory.

## Data safety
- This patch changes UI only. It does not replace places, offers, users, uploaded logos, or database content.
